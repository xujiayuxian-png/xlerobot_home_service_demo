# xlerobot_feetech

This package is the only project adapter around the pinned
`third_party/SCServo_Linux` SDK. Domain and task packages must not include the
vendor SDK directly.

Provenance: migrated from the verified prototype tag
`prototype-fetch-deliver-verified-20260709`, pinned to SDK commit
`da2ed3acab00a9da69dedff914b4c69e89e93aa8`.
